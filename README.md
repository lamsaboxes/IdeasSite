# موقع لمسة

مكتبة أفكار لصناديق لمسة (الرسم على الأكواب والأطباق).

## محتويات المجلد

```
index.html            الصفحة الرئيسية
404.html              صفحة "الصفحة غير موجودة"
css/style.css         التصميم
js/app.js             كل الإعدادات والحركة (الإعدادات في أول الملف)
logo.png              الشعار (الهيدر والفوتر)
ورود بيضاء.png        ورود المرج
زهرة زرقاء.png
وردة صفراء.png
ورد بنفسجي.png        (احتياط، مو مفعّلة)
وردة زرقاء نائمة.png  (احتياط، مو مفعّلة)
og-image.jpg          الصورة اللي تطلع لما ينرسل رابط الموقع
favicon.png           أيقونة التبويب
apple-touch-icon.png  أيقونة الجوال
robots.txt / .nojekyll
```

## قبل الرفع: صور لازم تضيفينها

حطّي هذي الصور جنب `index.html` (في نفس المكان، مو داخل مجلد) بنفس الأسماء اللي في الكود:

| الملف | وش هو |
|---|---|
| `1.png` | غيمة ١ |
| `2.png` | غيمة ٢ |
| `3.png` | غيمة ٣ |
| `4.png` | الشمس |

## الإعدادات (في أول ملف `js/app.js`)

- `SHARE.email`: إيميل استقبال صور "شاركنا لمستك".
- `LINKS.store`: رابط المتجر لما يجهز.
- `SCENE`: صور المشهد وإعداداته.

## خطوات النشر على GitHub Pages

1. أنشئي مستودع جديد (Repository) في GitHub، وخلّيه **Public**.
2. ارفعي **محتوى** المجلد (مو المجلد نفسه)، يعني `index.html` يكون في أول المستودع.
3. من **Settings ← Pages**:
   - Source: **Deploy from a branch**
   - Branch: **main** والمجلد **/ (root)** ثم Save.
4. بعد دقيقة أو دقيقتين يطلع رابط الموقع فوق في نفس الصفحة.
5. فعّلي **Enforce HTTPS** في نفس الصفحة.

## بعد النشر

- **صورة المشاركة في الواتساب:** افتحي `index.html` وغيّري
  `content="og-image.jpg"` إلى الرابط الكامل، مثل:
  `https://USERNAME.github.io/REPO/og-image.jpg`
- **تفعيل الإيميل:** أرسلي صورة تجريبية من الموقع، وأكّدي رسالة FormSubmit اللي توصلك.
  بعد التأكيد يعطونك رمز طويل يقوم مقام الإيميل، حطّيه في `SHARE.email` بدل إيميلكم عشان ما يبان في كود الموقع.
